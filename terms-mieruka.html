家づくり見える化パック 特則

有料サービス「家づくり見える化パック」にお申込みいただく場合の特則です。

本特則（以下「本特則」といいます。）は、Ac・Connect 株式会社（以下「当社」といいます。）が「これからのすまい」に付随して提供する有料サービス「家づくり見える化パック」の利用条件を定めるものです。

本サービスを利用される方は、本特則のほか、「Ac・Connect 株式会社 共通利用規約」、「くらしのつむぎ 利用規約」および「これからのすまい 利用特則」をご確認のうえ、お申し込みください。

第1条　適用

  1. 本特則は、当社が提供する「家づくり見える化パック」（以下「本サービス」といいます。）を申し込み、または利用する利用者に適用されます。
  2. 本特則に定めのない事項については、「これからのすまい 利用特則」、「くらしのつむぎ 利用規約」および「Ac・Connect 株式会社 共通利用規約」が適用されます。
  3. 本特則と上位規約その他の条件が矛盾または抵触する場合は、上位規約に定める優先順位に従うものとします。

第2条　本サービスの目的

  1. 本サービスは、住宅取得または住宅建築を検討する利用者に対し、候補地および利用者から提供された希望条件等に基づき、住宅計画を具体的にイメージするための参考資料を作成し、提供することを目的とします。
  2. 本サービスは、建築請負契約、設計契約、工事監理契約、不動産売買契約その他これらに類する契約を締結するものではありません。
  3. 本サービスによって提供する図面、画像、資金計画その他の成果物は、利用者が住宅計画を検討するための参考資料であり、そのまま建築、確認申請、工事、融資審査その他の手続に使用することを目的とするものではありません。

第3条　基本サービスの内容

  1. 本サービスの基本サービスには、原則として次の成果物が含まれます。
    1. 候補地に合わせた参考配置図
    2. 参考平面プラン
    3. 外観パース
    4. 前各号の計画に連動した簡易資金計画表
  2. 前項の成果物は、利用者から提供された土地情報、希望条件、予算その他の情報をもとに、当社所定の方法により作成します。
  3. 成果物の具体的な形式、枚数、表示内容その他の仕様については、本サービスの案内ページ、申込画面その他当社が別途提示する内容によります。
  4. 本サービスには、現地測量、地盤調査、法令調査、構造計算、設備設計、実施設計、確認申請、詳細見積りその他専門的または詳細な調査・設計業務は含まれません。ただし、当社が別途明示した場合を除きます。

第4条　基本料金

  1. 本サービスの基本料金は、1 契約につき 22,000 円（税込）とします。
  2. 前項の料金には、第 3 条に定める基本サービスが含まれます。
  3. 支払方法および支払時期については、申込画面その他当社が別途表示する方法によります。
  4. 振込手数料その他利用者の支払手続に伴い発生する費用がある場合は、別途明示がある場合を除き、利用者の負担とします。

第5条　内観パース

  1. 利用者は、希望する場合、基本サービスに加えて内観パースの作成を申し込むことができます。
  2. 内観パースの料金は、1 枚につき 7,700 円（税込）とします。
  3. 内観パースの作成対象となる空間、方向、仕様その他必要な条件については、利用者と当社との間で確認のうえ決定します。
  4. 内観パースは完成後の室内を保証するものではなく、住宅計画を視覚的に確認するための参考イメージです。

第6条　申込みおよび契約成立

  1. 利用者は、当社所定の方法により、本サービスの内容、料金、本特則その他必要事項を確認したうえで申し込むものとします。
  2. 当社は、対象となる土地、利用者の希望条件その他必要事項を確認し、本サービスの提供可否を判断します。
  3. 当社担当者の承諾通知が利用者に届いた時点で契約が成立します。ただし、当社が事前にサービス内容・料金・利用条件を確定し、申込みにより契約が成立する旨をご案内した場合は、Web上でのサービス申込みを当社が受信した時点、または対面でサービス申込書を当社担当者が受け取った時点で契約が成立します。お問い合わせフォームの送信およびその自動返信メールによって契約が成立するものではありません。
  4. 当社は、契約成立後、速やかに成果物の制作に着手します。
  5. 当社は、契約成立前に、次の各号のいずれかに該当する場合、申込みを承諾しないことがあります。
    1. 本サービスの作成に必要な情報または資料が不足している場合
    2. 対象となる土地または住宅計画について、本サービスによる成果物の作成が困難である場合
    3. 利用者の希望内容が本サービスの提供範囲を著しく超える場合
    4. 法令、技術上その他の理由により適切な成果物の作成が困難である場合
    5. 利用者が上位規約または本特則に違反している場合
    6. その他、当社が本サービスの提供が困難または適切でないと合理的に判断した場合
  6. 第3項ただし書により契約が成立する場合を除き、当社が申込みを承諾しない場合、当該申込みについて本サービスの契約は成立しません。

第7条　利用者から提供いただく情報

  1. 利用者は、本サービスの作成に必要な範囲で、次のような情報または資料を当社へ提供するものとします。
    1. 候補地に関する所在地、面積、形状その他の情報
    2. 土地資料、販売図面、公図、測量図その他保有している資料
    3. 希望する住宅の規模、間取り、階数、用途その他の条件
    4. 家族構成および生活上の希望
    5. 予算その他資金計画に必要な情報
    6. その他当社が成果物の作成に必要と判断する情報
  2. 利用者は、可能な範囲で正確かつ最新の情報を提供するものとします。
  3. 利用者から提供された情報に誤り、不足または変更があったことにより成果物と実際の条件に相違が生じた場合、当社の責めに帰すべき事由がある場合を除き、当社はその相違について責任を負わないものとします。

第8条　土地に関する前提

  1. 本サービスは、利用者から提供された資料その他当社が確認可能な情報に基づいて作成します。
  2. 当社が別途明示して実施する場合を除き、本サービスには、対象地についての現地測量、境界確認、地盤調査、インフラ調査、行政調査その他詳細な調査は含まれません。
  3. 対象地に関する接道、用途地域、建ぺい率、容積率、高さ制限、斜線制限、防火規制、条例その他の法令上または行政上の条件について、成果物作成時点で確認できない事項がある場合があります。
  4. 実際に住宅を建築する際には、住宅会社、設計者、宅地建物取引業者、行政機関その他必要な専門家または事業者による正式な調査および確認が必要です。

第9条　参考プランの性質

  1. 参考配置図および参考平面プランは、住宅計画の検討を目的とした参考資料です。
  2. 成果物に表示された建物が、対象地においてそのまま建築可能であることを保証するものではありません。
  3. 実際の設計に際しては、法令、構造、安全性、施工方法、設備、敷地条件、住宅会社の商品仕様その他の事情により、参考プランから変更が必要となる場合があります。
  4. 利用者が住宅会社その他の事業者と具体的な住宅計画を進める際には、当該事業者による正式な設計、確認および見積りを受けるものとします。

第10条　パースの性質

  1. 外観パースおよび内観パースは、住宅計画を視覚的に把握するための参考イメージです。
  2. パースに表示される色、質感、素材、家具、植栽、照明、周辺環境その他の表現は、実際の完成物と異なる場合があります。
  3. パースに表示された設備、家具、外構その他の物品等が、住宅建築費または簡易資金計画に含まれていることを意味するものではありません。
  4. 実際の仕様、色、素材その他については、住宅会社その他の契約先との間で別途確認するものとします。

第11条　簡易資金計画

  1. 本サービスで提供する簡易資金計画表は、利用者の住宅取得計画を検討するための参考資料です。
  2. 簡易資金計画に記載される土地代金、建物価格、諸費用、住宅ローン、金利、税金、保険料その他の金額は、作成時点で確認可能な情報または一定の仮定に基づく参考値を含む場合があります。
  3. 実際の住宅取得費用、工事費、諸費用、融資条件、税金その他の金額を保証するものではありません。
  4. 正式な資金計画については、不動産会社、住宅会社、金融機関、税理士その他必要な事業者または専門家による確認を受けるものとします。

第12条　成果物の納品

  1. 当社は、本サービスの成果物が完成した後、電子メール、オンライン上での共有、データ送付その他当社所定の方法により利用者へ納品します。
  2. 具体的な納品方法および納品予定時期については、申込み時または申込み後に当社が案内します。
  3. 利用者から必要な資料または回答の提供が遅れた場合その他利用者側の事情により作業を進めることができない場合、納品時期が変更となることがあります。
  4. 本サービスは、当社が所定の成果物を納品することにより、1 契約分のサービス提供を完了したものとします。

第13条　訂正および再作成

  1. 本サービスにより提供する成果物は、利用者から申込み時に提供された土地情報、希望条件その他の情報に基づいて当社が作成する参考資料であり、納品後の利用者の希望による修正、変更または調整はお受けしません。
  2. 成果物に、当社の責めに帰すべき明らかな誤記、転記誤りその他の不備がある場合には、当社は合理的な範囲で訂正します。
  3. 利用者が、納品後に間取り、建物規模、配置その他の内容の変更を希望する場合は、当初の契約に基づく修正としては取り扱いません。
  4. 次の各号に該当する場合その他新たな成果物の作成を希望する場合は、新たな申込みとして取り扱います。
    1. 対象となる土地を変更する場合
    2. 住宅の規模、階数または構成を変更する場合
    3. 間取りまたは配置等の変更を希望する場合
    4. 申込み時に提示された希望条件その他の前提条件を変更する場合
    5. その他、利用者が別の計画による成果物の作成を希望する場合
  5. 前項により新たな申込みを行う場合は、改めて基本料金 22,000 円（税込）が発生します。
  6. 内観パースを追加して申し込む場合は、1 枚につき 7,700 円（税込）が発生します。

第14条　契約成立後のキャンセル等

  1. 本サービスは、利用者ごとの土地情報、希望条件その他の個別事情に基づいて制作するサービスであり、当社は契約成立後、速やかに成果物の制作に着手します。
  2. 契約成立後は、利用者の都合による申込みの撤回、キャンセル、契約解除および返金はお受けしません。
  3. 前項にかかわらず、法令上利用者による解除その他の権利が認められる場合は、この限りではありません。
  4. 契約成立後、対象地の状況、利用者の希望内容、技術上の事情その他の理由により、当社が適切な成果物を制作することが困難であると合理的に判断した場合、当社は利用者へ通知したうえで本サービスの提供を終了することができます。
  5. 前項の場合において、利用者から本サービス料金を既に受領しているときは、当社は当該申込みに係る本サービス料金を全額返金します。
  6. 前項による返金をもって、当該申込みに係る本サービスは終了するものとします。

第15条　成果物の利用

  1. 利用者は、本サービスにより納品された成果物を、自らの住宅計画その他の目的のため、自由に利用、保存、複製、改変し、または不動産会社、住宅会社その他の第三者へ提供することができます。
  2. 当社は、法令上許容される範囲で、利用者による成果物の利用方法を制限しません。
  3. 前各項は、第三者の権利を侵害する利用その他法令に違反する利用を認めるものではありません。

第16条　成果の非保証

当社は、本サービスについて、次の事項を保証するものではありません。

  1. 参考プランどおりの住宅が建築できること
  2. 対象地について建築確認その他必要な許認可が得られること
  3. 参考プランどおりの価格で住宅が建築できること
  4. 簡易資金計画どおりの費用で住宅を取得できること
  5. 住宅ローンその他の融資が承認されること
  6. パースと実際の完成物が完全に一致すること
  7. 土地の取得または住宅会社との契約が成立すること
  8. その他利用者が希望する結果が実現すること

第17条　上位規約の適用

本特則に定めのない事項については、「これからのすまい 利用特則」、「くらしのつむぎ 利用規約」および「Ac・Connect 株式会社 共通利用規約」が適用されます。

特に、次の事項については上位規約の定めに従います。

  1. 禁止事項
  2. 個人情報等の取扱い
  3. サービスの変更、中断等
  4. 利用制限等
  5. 免責および損害賠償責任
  6. 反社会的勢力の排除
  7. 規約変更
  8. 準拠法および合意管轄
  9. その他上位規約に定める事項

第18条　本特則の変更

本特則の変更については、「Ac・Connect 株式会社 共通利用規約」に定める規約変更の規定に従います。
