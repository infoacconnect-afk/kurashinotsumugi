# 診断結果の問い合わせ添付

PR22の承認済み診断改修は2026-11-04に本番反映。追加機能は別の試用版として確認する。

結果画面の相談ボタンで、5問の質問・回答、結果見出し・説明・理由・確認事項・注意書きを同じタブのフォームへ引き継ぐ。PDFではなく読みやすいテキストとして既存のmessageに追記し、GASのシート・管理者通知・返信の既存本文処理を使う。GASのデプロイ変更は不要。

診断だけでは保存・送信しない。相談ボタンを押した時のみsessionStorageへ一時保存。有効期限30分、バージョン・型・文字数・時刻を検証し、取り外し・診断のやり直し・送信成功時に消去。URLやGA4に回答を入れない。フォームの同意は選択しない。添付表示はtextContentで挿入する。

フォームで全内容を確認・折りたたみ・取り外し可能。送信失敗時は残す。期限切れ・別結果への変更は送信を止めて解除を通知し、添付なし送信には再操作を必要とする。相談本文と添付の合計5000文字の既存GAS制限を維持。通常の問い合わせでは保存済みの結果を勝手に添付しない。保存不可は結果画面で案内。

FAQの保存・送信説明を実装に合わせて更新。料金・規約・canonical・サイトマップの変更は不要。既存の構造化データ・OGP生成を継続し、試用版はnoindex。

検証：26テスト成功（診断640通り、GA4の27シナリオを含む）。送信本文は通信を差し替えたテストで添付・取り外し・期限切れを確認。実際の問い合わせ・メール送信は行わない。実機スマホは未検証。
