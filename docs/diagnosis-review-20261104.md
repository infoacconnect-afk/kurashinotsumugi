# ゼロ診断の仕様確認（2026年11月4日）

確認元：akiya-shindan.html の questions / showResult / renderStep、assets/contact-form.js。サイトの診断ロジックはブラウザ内で動く定型条件分岐で、AI API、査定・賃料・費用の計算はない。

## 今回の変更
所在地の4選択肢を、次の2選択肢へ変更。その他の質問、結果判定、文章、デザイン、演出は維持する。試用版のみ。本番は所有者の承認後。
- 関東（埼玉県・東京都・神奈川県・千葉県・茨城県・栃木県・群馬県）
- 関東以外の地域（所在地により個別にご相談）
所在地を選ぶことは、当該地域での対応・借上げを保証するものではない。関連FAQの個別相談方針と整合させた。検索メタ情報に旧地域区分の重複記載はない。

## 現在の仕様
固定順の5問：所在地、建物状態、利用状況、維持負担感、今後の希望。質問自体は回答に応じて変わらない。選択後260msで次へ。戻る・やり直しあり。
所在地は変数locに読み込むだけで、結果に使っていない。残り4問で5種類の定型結果から1種類を返す。上から最初に一致する条件が採用される。

|優先順|条件（先に一致したものが優先）|結果|
|---|---|---|
|1|持ち続けたい、かつ負担が「かなり」以外|持ち続けるをもっとラクに|
|2|誰かに使ってほしい、または空き家かつ状態が「手入れが必要／傷みが気になる」以外|誰かに使ってもらう|
|3|手放すことも含め整理したい、または負担がかなり重く状態に傷みがある|整理を丁寧にお手伝い|
|4|状態に傷みがある、または状態が不明|家の状態を知る|
|5|上記以外|ゆっくり相談|

回答はページ内のJavaScript変数に保持され、再読み込みで消える。診断専用の回答保存・送信処理はない。ただしサイト一般のアクセス解析とは別の話であり、すべての通信や記録がないとは断定しない。
相談ボタンは contact.html?service=shindan へ移動し、問い合わせ項目を選択する。5問の回答・結果は引き継がない。
費用がゼロになる判定、借上げの可否、地域の市場性、税額、修繕費の評価は行わない。

## 実行確認
変更後512通り（2×4×4×4×4）について、各地域の変更前結果と比較。所在地だけの変更で結果が変化しないことを確認。
- 手放す希望＋空き家＋古いが住める → 整理ではなく活用が優先される。
- 状態不明＋空き家＋希望未定 → 状態確認ではなく活用が優先される。
