# 検索・AI検索向け整備（2026-11-03）

## 現状確認
- 本番robots.txtは200、User-agent: * / Allow: /。Googlebot、Bingbot、OAI-SearchBot等をrobotsで拒否していない。実際の各社ボットによる取得・引用は未確認。AI学習への許諾は今回変更していない。
- サイトマップと主要ページ・記事はHTTP 200。拡張子あり/なしのFAQは両方200で、既存canonicalに統一されているためURL移行は行わない。
- 接続済みSearch Consoleで、サイトマップの最終取得は2026-11-02T14:05:28.255Z、エラー・警告0。2026-10-07〜11-02に検索表示データを取得。全URLの登録・検索順位・AI引用を保証するものではない。
- 既存のtitle/description/canonical/OGP、記事の初期HTML、会社・サービス・パンくず、サイトマップ、計測除外、PC/スマホ向け配信軽量化は維持。

## 今回の改善
1. FAQページの28件を、そのページの質問・回答本文からFAQPage/Question/Answerとして自動生成。別ページの同じFAQには重ねて追加しない。価格・条件・対応地域を機械用に別途創作しない。
2. 質問文由来の安定したフラグメントIDを付与。直接リンクを開くと該当カテゴリ・回答が開き、固定ヘッダーの下に表示。通常のタブ・開閉演出は維持。
3. JavaScriptなし用の既存noscriptにHTMLがエスケープされる不具合を修正。FAQの全カテゴリ・全回答、記事一覧の全記事リンク、fade-up本文が実際に読み取れるよう修正。一般閲覧時のデザインは変更しない。
4. 運営会社・ブランド・WebSite・Service・Articleの識別子と関係を統一。会社概要はAboutPage、問い合わせはContactPage、記事一覧はCollectionPageとして明示。無料診断ページも既存説明由来のServiceを付与。
5. 会社所在地の改行を空白に変換し、郵便番号と住所の連結を防止。問い合わせ先は既存の公開電話・フォームのみ。
6. CMSの更新日時がISO日時形式の場合もサイトマップlastmodへ出力。ビルド日時を記事更新日時として偽装しない。
7. ローカルプレビュー設定ディレクトリを配信対象外にする。

## 施策の位置づけ
SEO/AEO/AIO/LLMOの共通基盤を改善する変更。FAQ構造化データだけでGoogleのFAQリッチリザルトやAI引用が得られるとは扱わない。GoogleはAI向け特別マークアップやllms.txtを必要としていない。学習用GPTBotへの許可とChatGPT検索用OAI-SearchBotは別の目的。不要なファイル追加・キーワードの詰め込み・架空の評価/実績/専門家監修は行わない。
