Ac・Connect株式会社 共通利用規約

当社が提供するすべてのサービスに共通して適用される利用規約です。

本共通利用規約（以下「本規約」といいます。）は、Ac・Connect 株式会社（以下「当社」といいます。）が提供する各種ウェブサイト、サービス、システムその他当社が提供するサービスのうち、本規約の適用を明示したものについて、その共通の利用条件を定めるものです。

第1条　目的および適用

  1. 本規約は、当社が提供する各種サービスについて共通して適用される基本的な利用条件を定めることを目的とします。
  2. 本規約は、当社が運営または提供するウェブサイト、ウェブサービス、相談サービス、情報提供サービス、マッチングサービス、広告・集客支援サービス、制作サービス、システムその他のサービス（以下総称して「本サービス」といいます。）のうち、本規約の適用が明示されたものに適用されます。
  3. 本サービスごとに別途利用規約、利用特則、サービス条件、申込書、契約書、料金表その他の条件（以下総称して「個別規約等」といいます。）が定められている場合、利用者は本規約と併せて当該個別規約等に従うものとします。
  4. 本規約と個別規約等の内容が矛盾または抵触する場合は、次の順位で適用するものとします。ただし、別途明確な定めがある場合は、その定めを優先します。
    1. 個別の契約書、申込書、注文書その他当社と利用者との個別合意
    2. サービス別の特則
    3. サービス別の利用規約
    4. 本規約

第2条　定義

本規約において、次の各号の用語は、それぞれ次の意味で使用します。

  1. 「利用者」とは、本サービスを閲覧、問い合わせ、申込み、登録または利用する個人、法人その他の団体をいいます。
  2. 「提携事業者」とは、当社と業務提携、広告掲載、顧客紹介、業務委託その他の契約または協力関係を有する法人、個人事業主、専門家その他の事業者をいいます。
  3. 「個別サービス」とは、本サービスを構成する各ブランド、サービス、商品、機能またはシステムをいいます。
  4. 「投稿情報等」とは、利用者が本サービスを通じて当社に提供する文章、画像、動画、図面、物件情報、顧客情報、問い合わせ内容その他の情報または資料をいいます。

第3条　本規約への同意

  1. 利用者は、本規約の適用を明示された本サービスについて、当社所定の方法により本規約に同意した場合、本規約の内容に同意したものとします。
  2. 当社が本サービスの申込み、登録または利用に際して本規約への同意を求める場合、利用者は、本規約を確認したうえで同意するものとします。
  3. 単に当社ウェブサイトを閲覧する利用者については、本規約のうちウェブサイトの閲覧および利用の性質上適用される条項が適用されます。

第4条　利用条件

  1. 利用者は、法令、本規約、個別規約等および当社が別途定める利用条件に従って本サービスを利用するものとします。
  2. 本サービスの一部については、年齢、居住地域、事業者資格、免許・許認可、本人確認その他の利用条件を設ける場合があります。
  3. 未成年者が契約その他法定代理人の同意を必要とする行為を行う場合は、あらかじめ法定代理人の同意を得るものとします。
  4. 当社は、本サービスの性質上必要と判断する場合、利用者に対して本人確認、資格確認、権限確認その他必要な資料の提出を求めることがあります。

第5条　登録情報等

  1. 利用者は、本サービスの利用、申込みまたは問い合わせに際し、真実かつ正確な情報を提供するものとします。
  2. 利用者は、登録または提供した情報に変更が生じた場合、必要に応じて速やかに当社所定の方法により変更または通知するものとします。
  3. 利用者が虚偽、不正確または不十分な情報を提供したことにより本サービスの提供に支障が生じた場合、当社は、必要な範囲で本サービスの提供を保留、制限または終了することができます。

第6条　アカウント等の管理

  1. 本サービスにおいてアカウント、ID、パスワードその他の認証情報が発行される場合、利用者は自己の責任においてこれらを適切に管理するものとします。
  2. 利用者は、当社の承諾なく認証情報を第三者に譲渡、貸与、共有その他利用させてはなりません。
  3. 認証情報の漏えい、不正使用その他の異常を確認した場合、利用者は速やかに当社へ通知するものとします。

第7条　料金等

  1. 本サービスの料金、支払方法、支払時期、契約期間、解約条件、キャンセル条件その他の金銭的条件は、各個別規約等または当社が別途表示する条件によるものとします。
  2. 無料で提供される本サービスにおいても、利用者が別途有料サービスまたは有料オプションを申し込む場合には、当該サービスに定める料金が発生します。
  3. 当社は、本サービスの運営に関連して、提携事業者その他の第三者から広告料、利用料、業務委託料その他の対価を受領する場合があります。
  4. 前項の具体的な契約条件、金額、算定方法、支払条件その他当社と提携事業者等との取引条件については、当該当事者間の個別契約によるものとします。

第8条　提携事業者等の紹介

  1. 当社は、本サービスの提供に関連して、利用者に対し、建築会社、不動産会社、工事会社、管理会社、金融機関、士業その他の提携事業者を紹介し、またはこれらの事業者に利用者を接続する場合があります。
  2. 当社が別途契約当事者となることを明示している場合を除き、利用者と提携事業者との間で成立する契約は、利用者と当該提携事業者との間で直接成立するものとします。
  3. 提携事業者が提供する商品、サービス、業務、説明、見積り、契約条件その他の内容については、当該提携事業者がその責任を負うものとします。
  4. 当社による提携事業者の紹介は、利用者と当該事業者との契約成立、審査通過、融資承認、工事完成、取引成立その他一定の結果を保証するものではありません。
  5. 当社が紹介する事業者は、当社と提携その他の関係を有する事業者の中から選定する場合があり、市場に存在するすべての事業者を網羅的に比較、評価または紹介することを意味するものではありません。

第9条　情報・助言等の性質

  1. 当社が本サービス上で提供する記事、シミュレーション、参考資料、査定、参考プラン、資金計画、事例その他の情報は、個別規約等に別段の定めがある場合を除き、一般的または参考的な情報として提供するものです。
  2. 法律、税務、登記、建築、金融、不動産その他専門資格を要する個別具体的な判断については、必要に応じ、適切な資格を有する専門家または事業者による確認を要する場合があります。
  3. 当社は、法令または個別契約により特定の結果を保証する場合を除き、本サービスの利用によって利用者が希望する結果、利益、契約成立その他の成果が得られることを保証するものではありません。

第10条　投稿情報等

  1. 利用者は、当社に提供する投稿情報等について、提供する正当な権限を有することを保証するものとします。
  2. 利用者は、当社が本サービスの提供、問い合わせ対応、審査、提案、業務遂行、記録管理その他本サービスの運営に必要な範囲で投稿情報等を利用することに同意するものとします。
  3. 投稿情報等に第三者の著作物、肖像、個人情報その他第三者の権利に関する情報が含まれる場合、利用者は必要な承諾その他適法な手続きを自己の責任において行うものとします。
  4. 当社が投稿情報等を広告、ウェブサイト、SNS その他一般公開される媒体に掲載する場合は、利用者自身が公開を目的として提供した場合その他正当な根拠がある場合を除き、必要に応じて別途承諾を取得します。

第11条　知的財産権

  1. 本サービスおよび本サービスに関連するウェブサイト、文章、画像、動画、ロゴ、名称、デザイン、プログラム、システムその他のコンテンツに関する著作権、商標権その他の知的財産権は、当社または正当な権利を有する第三者に帰属します。
  2. 利用者は、法令上認められる場合を除き、当社または権利者の承諾なく、これらを複製、転載、改変、頒布、公衆送信、販売その他利用してはなりません。
  3. 個別サービスにおいて制作物の権利帰属について別段の定めがある場合は、当該個別規約等が優先します。

第12条　禁止事項

利用者は、本サービスの利用にあたり、次の各号に該当する行為をしてはなりません。

  1. 法令または公序良俗に違反する行為
  2. 犯罪行為または犯罪行為に関連する行為
  3. 虚偽または不正確な情報を故意に提供する行為
  4. 他人になりすます行為
  5. 当社または第三者の著作権、商標権、肖像権、プライバシー、名誉、信用その他の権利または利益を侵害する行為
  6. 当社または第三者に対する詐欺、脅迫、誹謗中傷、嫌がらせその他不当な行為
  7. 本サービスの運営を妨害し、またはそのおそれのある行為
  8. 本サービスのシステム等に対する不正アクセス、過度な負荷、解析、改変その他不正な操作
  9. 当社の承諾なく、本サービス上の情報を営業目的その他本来の目的を超えて収集または利用する行為
  10. 反社会的勢力への利益供与その他これに関連する行為
  11. その他、当社が本サービスの適正な運営上不適切と合理的に判断する行為

第13条　サービスの変更、中断等

  1. 当社は、本サービスの改善、法令改正、システム変更、事業上の必要その他合理的な理由がある場合、本サービスの全部または一部の内容を変更することがあります。
  2. 当社は、次の各号に該当する場合、本サービスの全部または一部を一時的に停止または中断することがあります。
    1. システムの点検、保守または更新を行う場合
    2. 通信回線、クラウドサービスその他外部サービスに障害が生じた場合
    3. 地震、台風、洪水、火災、停電その他の不可抗力が発生した場合
    4. 法令、行政機関、裁判所その他公的機関から必要な措置を求められた場合
    5. その他、本サービスの継続が困難であると当社が合理的に判断した場合
  3. 緊急の場合を除き、当社は、利用者への影響が大きい変更、停止または終了について、合理的な方法により事前に案内するよう努めます。

第14条　利用制限等

当社は、利用者が次の各号のいずれかに該当する場合、必要な範囲で、本サービスの利用停止、登録取消し、契約解除その他適切な措置を講じることができます。

  1. 本規約または個別規約等に違反した場合
  2. 登録情報等に重要な虚偽が判明した場合
  3. 支払義務があるにもかかわらず、正当な理由なく支払を怠った場合
  4. 当社、提携事業者その他第三者に重大な損害または業務妨害を与えた場合
  5. 反社会的勢力に該当し、または関係があると合理的に認められる場合
  6. その他、本サービスの提供を継続することが著しく困難または不適切であると合理的に判断される場合

第15条　免責および責任

  1. 当社は、本サービスについて、法令または個別規約等において明示的に保証する場合を除き、完全性、正確性、最新性、特定目的への適合性、継続性その他一定の結果を保証するものではありません。
  2. 当社は、当社の責めに帰すべき事由により利用者に損害を生じさせた場合、法令に従い責任を負います。
  3. 当社の故意または重大な過失による場合を除き、当社が損害賠償責任を負う場合の範囲については、法令上認められる範囲で、当社の行為と相当因果関係のある通常かつ直接の損害を対象とします。
  4. 利用者が消費者契約法上の消費者に該当する場合、本条その他本規約の責任制限または免責に関する規定は、同法その他の強行法規により認められる範囲で適用されます。
  5. 提携事業者その他第三者の責任に帰すべき行為について、当社が当該行為の契約当事者または責任主体でない場合、当社は当該第三者に代わって責任を負うものではありません。ただし、当社自身の責めに帰すべき事由がある場合を除きます。

第16条　個人情報等

  1. 当社は、利用者の個人情報を、個人情報の保護に関する法律その他関係法令および当社が別途定めるプライバシーポリシーに従って適切に取り扱います。
  2. 本サービスにおいて提携事業者その他第三者への個人データの提供が必要となる場合、当社は、法令に基づく場合を除き、必要に応じて本人の同意を取得するなど、法令に従った措置を講じます。
  3. 個別サービスにおいて個人情報の取得、利用または第三者提供について別途同意事項が定められている場合、当該同意事項が併せて適用されます。
  4. 当社は、本サービスの品質向上、問い合わせ対応、業務管理その他プライバシーポリシーに定める目的の範囲内で、利用者との対応履歴その他必要な記録を保存する場合があります。

第17条　通知および連絡

  1. 当社から利用者への通知または連絡は、本サービス上への掲示、電子メール、SMS、電話、書面その他当社が適切と判断する方法により行います。
  2. 利用者は、当社からの重要な通知を受信できるよう、登録情報を適切に維持するものとします。
  3. 利用者が登録情報の変更を怠ったこと等により通知を受領できなかった場合であっても、当社が通常必要とされる方法で通知を行ったときは、法令に別段の定めがある場合を除き、当社は当該不達について責任を負わないものとします。

第18条　反社会的勢力の排除

  1. 利用者および当社は、それぞれ、自らまたは自らの役員その他実質的に経営に関与する者が、暴力団、暴力団員、暴力団関係企業、総会屋、社会運動等標ぼうゴロ、特殊知能暴力集団その他これらに準ずる反社会的勢力に該当しないことを表明し、将来にわたって該当しないことを確約します。
  2. 利用者および当社は、反社会的勢力を利用し、資金提供もしくは便宜供与を行い、またはこれらと社会的に非難されるべき関係を有してはならないものとします。
  3. 相手方が本条に違反した場合、相手方は、催告その他の手続きを要せず、法令上認められる範囲で契約解除その他必要な措置を講じることができます。

第19条　権利義務の譲渡等

  1. 利用者は、当社の事前の承諾なく、本規約または本サービスに基づく契約上の地位、権利または義務を第三者に譲渡、移転、担保設定その他処分してはなりません。
  2. 当社が、本サービスに係る事業を第三者へ譲渡し、会社分割、合併その他の組織再編等により承継させる場合、当社は、法令および個別契約に従い、本サービスに係る契約上の地位、権利義務その他必要な関係を当該承継先へ移転することがあります。
  3. 前項に伴う個人情報等の取扱いについては、個人情報保護法その他関係法令に従います。

第20条　本規約の変更

  1. 当社は、法令の改正、本サービスの変更、社会情勢または事業環境の変化その他の事情により、本規約を変更する必要が生じた場合、民法その他関係法令に従い、本規約を変更することがあります。
  2. 当社が本規約を変更する場合、変更後の内容および効力発生日を、本サービス上への掲示その他適切な方法により周知します。
  3. 法令上利用者の個別の同意が必要となる変更については、当社は所定の方法により利用者の同意を取得します。

第21条　分離可能性

本規約または個別規約等の一部の条項が法令等により無効または執行不能と判断された場合であっても、その他の条項は引き続き有効に存続するものとします。

第22条　準拠法

本規約、本サービスおよび当社と利用者との契約関係には、日本法を準拠法として適用します。

第23条　合意管轄

本規約または本サービスに関して当社と利用者との間に紛争が生じた場合、法令に別段の定めがある場合を除き、法令上認められる範囲で、さいたま地方裁判所または大宮簡易裁判所を第一審の専属的合意管轄裁判所とします。

第24条　協議

本規約または個別規約等に定めのない事項、またはその解釈について疑義が生じた場合、当社および利用者は、法令および取引上の信義則に従い、誠実に協議して解決するものとします。
